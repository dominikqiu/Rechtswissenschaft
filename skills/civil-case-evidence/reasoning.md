# 推理协议（衍生版新增）

每个争点构成一个可审查单元：

| 字段 | 要求 |
| --- | --- |
| question | 限定到特定要件、抗辩、救济范围或时间适用问题 |
| proposition | 规则命题及来源定位；区分原文规则、裁判归纳和本案推论 |
| sources | 具体条文版本或裁判/文献段落，不以整本书名替代 |
| facts | 对应事实 ID，列支持与不利事实，未知另列 |
| application | 解释事实为何满足或不满足命题，不能只复述事实和法条 |
| counterargument | 有依据的反对解释或事实分支；不存在重要反对材料时说明检索范围，不编造学说 |
| conclusion | 支持、不支持、条件成立或尚不能判断，写明改变结论的关键条件 |

明显问题简写；争议问题充分说明不同解释会如何改变结果。不要设最低字数或强制六种解释齐全。

解释方法按需使用：文义确定边界；体系考察相邻规则与规范功能；历史解释须有对应立法资料；目的解释区分可证的立法目的与分析者的规范论证；比较法须有可靠外国法来源并说明本土适用限度；合宪解释须说明关联及边界。方法之间发生冲突时给出法律上的选择理由，不虚构量化权重。

对裁判类推，比较关键事实、请求类型、规范版本和裁判理由；指出差异能否改变结论。不得将个别判决称为通说，不以搜索排名或数量直接推断效力。

对核心结论做反事实检验：改变哪个关键事实或适用规则会改变结果？若没有任何因素可能改变结论，检查是否发生先定结论再挑选依据。该检验产出简短条件说明即可。

知识库与模型意见一致不构成独立验证；重复转载同一裁判也不是多份独立证据。对直接反对材料必须回应其适用范围、效力或事实差异。法律依据不足可给出有明确身份的暂拟解释，但不得声称其为现行定论。
