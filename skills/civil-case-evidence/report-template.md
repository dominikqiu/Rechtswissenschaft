# 案例分析报告

> 状态：provisional / reviewed；法域：；分析日期：；案件相关时点：。
> reviewed 仅指本工作流审查完成，不表示法院结论或外部法律意见认证。

## 问题、事实与范围

列问题与救济目标；事实 ID 及材料定位；单列争议和未知事项。说明本次检索范围和资料限制。

## 请求权候选与分析大纲

列主体方向、请求内容、请求权/形成权/防御规则性质、选入或排除理由、竞合和主备位关系。

## 逐项分析

按请求权产生、未消灭、可行使组织；形成权前提依制度调整。各争点列 issue ID，阐明规则、事实涵摄、反对依据和结论。正文引用与 sources 的 ID 对应；关键条文引用相关完整句段，完整版本定位放来源表，不机械复制全部法律。

## 结论与条件

说明谁能向谁主张什么、范围和条件；区分确定结果、备位结果和待核事项，避免同一损失重复受偿。

## 来源与审查

列 sources 的名称、版本、条款/页码/案号、链接或本地材料定位、查阅日期；列实际执行的结构检查与实质复核、遗留问题。格式按用户需要选择，不强制九级标题。
